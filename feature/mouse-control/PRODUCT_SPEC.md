# 鼠标控制：产品规范

本文只定义用户可观察的行为，不定义实现细节。实现、涉及文件与验证记录见同目录 [`README.md`](README.md)，验证方法见 [`Testing/MouseControlMode.md`](../../Testing/MouseControlMode.md)。

## 1. 鼠标点击与鼠标移动动作

- “系统与媒体”分组提供七个预设动作：鼠标左键、鼠标右键、鼠标中键、鼠标上移、鼠标下移、鼠标左移、鼠标右移。
- 点击动作在**当前光标位置**点击一次，不寻找、也不点击界面高亮项。
- 移动动作每次沿该方向移动固定距离，光标到屏幕边缘即停住；按住时沿用该按键原有的连发设置。
- 点击与移动动作都不需要进入鼠标模式，可绑定单击、双击或长按。
- 需要辅助功能权限；权限缺失时走既有权限提示链路，动作不执行。

## 2. 鼠标模式

- 进入与退出：绑定“切换鼠标模式”动作到任意按键，按下即切换；鼠标模式内按默认绑定，返回键单击也退出；遥控器断开、HID 监视器停止、权限被回收、App 退出时自动退出。激活状态不持久化。
- 模式内被接管的按键只有六个：上、下、左、右、确定、返回。其余按键（菜单、主页、音量、电源等）保持自己的键盘键位。
- 默认绑定：
  - 上 / 下 / 左 / 右单击 = 光标移动：按住时按二次缓入曲线加速，前段精调、后段快速，支持斜向，到屏幕边缘停住。最高速度与加速时长在“鼠标设置”里选档，见第 4 节。
  - 确定单击 = 鼠标左键；确定双击 = 鼠标右键；确定长按 = 回车（用于聊天工具发送）。
  - 返回单击 = 退出鼠标模式。
  - 六个键的其余触发（双击 / 长按）默认无动作。
- 只有在本模式内按下过的确定，松开时才会产生点击。
- 菜单栏图标在模式激活期间切换为高亮样式；语音时长警告与严重状态比它更紧急，不被盖住。
- 鼠标模式只作用于实体遥控器链路。手机、Apple Watch、网页遥控不进入模式，但其按键可以绑定点击动作。

## 3. 键盘模式 / 鼠标模式分模式键位

- 按键页在页头下方提供模式切换：左侧选择正在编辑的模式（键盘模式 / 鼠标模式），右侧实时显示遥控器当前真正在运行的模式。编辑态与运行态可以不同，两者必须同时可见。
- 鼠标模式用橙色作为模式色，键盘模式沿用系统主题色：选中段填充、运行态胶囊、鼠标模式下的动作文字、六个可配卡片的淡底、描边以及选中态的底色与描边都用橙色；按键名图标保持中性。
- 上、下、左、右、确定、返回六个键按模式分别保存键位；其余按键两种模式共用键盘键位，卡片上标注“两种模式共用”。
- 鼠标模式的默认值见第 2 节。改过的键位在编辑器里提供“恢复默认”，回到默认动作。
- 鼠标模式不提供“按住时”入口：方向键按住即连续移动，按住面板与按住筛选在该模式不出现。
- 鼠标模式只编辑基础键位，不进入键位方案作用域。

## 4. 鼠标模式参数

- 入口：键盘页鼠标模式下，模式切换右侧出现“鼠标设置”，点开是四项三档预设。键盘模式下不出现。
- 项与档位：
  - 最高速度：慢 600 / 标准 1400 / 快 2200 点每秒；起步速度按档位给 80 / 160 / 250 点每秒。
  - 加速时长：短 0.4 / 标准 1.2 / 长 2.4 秒。
  - 双击间隔：短 0.2 / 标准 0.3 / 长 0.45 秒，决定确定键第二次按下算双击（右键）还是两次单击。
  - 长按时长：短 0.4 / 标准 0.55 / 长 0.8 秒，决定确定键按住多久算长按（回车）。
- 默认全部“标准”，与引入设置前的固定参数一致；“恢复默认”一次回到这套值。
- 四项是模式级、全局一份，不进键位绑定，也不进便携配置导出；换设备或换档案不改变它们。
- 只影响鼠标模式内的光标移动与确定键手势；键盘模式里绑定的“光标移动”动作始终用标准档。

## 5. 非目标

- 不做屏幕浮窗 HUD；不实现拖拽（按住确定拖动光标）。
- 不改变手机 / 手表 / 网页遥控的协议与既有动作下发内容；`mouseCursorMove` 与 `exitMouseMode` 不下发给这些端。
- 不为其余六个按键提供第二套键位。

## 6. 兼容边界

- 分模式键位的 `mode` 字段对旧版 App 是未知字段：旧版会把鼠标模式绑定当成键盘绑定，装回旧版属于既有前向不兼容行为。
- 新增动作的 raw 值在官方版不存在：装回官方版会整体回退全部自定义键位。
